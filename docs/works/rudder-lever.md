# 【26代引継】ラダーレバー製作の手引き
## 前提
- 対象の機体はエレベータを持たず，パイロットの体重移動によってピッチをコントロールする．
- ラダーの駆動はサーボモータによる「フライ・バイ・ワイヤ」システムである．

## 要求
1. パイロットが体重移動とラダー操作を同時に実施できるようにすること．
2. 確かな操舵反力（およそ1~2kg）が得られること．
3. 単体でサーボモータを制御できること（全機能喪失時のフェイルセーフ）．

## 要件
0. これまでの実績から，サーボモーターは[KRS-4034HV ICS](https://kondo-robot.com/product/krs-4034hv-ics)を使用する．
  - ラダーを駆動するのに十分とみられるトルク（41.7kgf・cm）が得られる．
  - サーマルシャットダウン（温度リミッター）の設定値を変更することで，最大約120℃まで動作させられる．
1. 左右独立のレバー式とし，フレームを握る手を離さずとも操作可能にする．
2. 復元力は引きバネにより得る（引っ掛ける場所さえあれば良いため）．
2. およそ1~2kgのラジアル荷重に耐えるセンサーにより角度を直接取得するか，何らかの方法で「操舵力」を直接取得する．
3. コストの問題から，マイコンを右レバーにのみ搭載し，サーボモータの制御信号を生成する．
3. 左レバーはマイコンを用いず，およそ1700mmのケーブルを経て右レバーに接続する．

## 分析
### センサー
- 抵抗式ポテンショメータには回転トルクが少なく非常に好ましいものがある（例. RDC50 : 2025竜海のラダーレバーで採用）が，**要求 2** より軸におよそ1~2kgの負荷がかかるため，センサーの物理的破損や角度読み取り誤差増大の恐れがある．
- 磁気式エンコーダ（AS5600など）は非接触かつ高分解能で回転量を読み取れるが，高コストである．
- **レバー自体をロードセルとして，操舵力を直接測定することにより，諸問題の一挙解決を図る．**
### ロードセルの選定
- 秋月にあるビーム（片持ち梁）型から選ぶ．
- 2kg，5kg，10kgが候補になるが，ロードセル自体の重量を抑えるべく，2kgを選定した．
  - 電装はピッチ方向の慣性モーメントについて，多少の憂慮をしなければならない．
- ロードセルの出力電圧は1mV/V（すなわち3.3V印加+最大負荷時は3.3mV出力される）．
### 構成
- ロードセルの出力を増幅する方法は以下
  1. HX711 24bitADCを利用する（定石，しかし頑張っても80Hzまでしかデータレートが出ない）．
  2. 計装アンプを使って増幅し，マイコンのADCで読み取る（RP Picoなら理論上，最大50万Hzのデータレート）．
