# 鳥科とは？

東京理科大学 葛飾キャンパスを拠点とする鳥人間サークルです．鳥人間コンテスト 滑空機部門に出場し，私たちで作った飛行機を琵琶湖の空に飛ばすために活動しています．

# 電装班とは？

機体に搭載する，電子機器の製作を担当している班です．

# 何を作っている？
さて、鳥コンの機体の電子機器が担う役割とは、”機体の操縦”と”フライトログ”の測定です。

”機体の操縦”については、パイロットが操縦桿を握った/動かした分だけ、
エレベータ/ラダーのサーボモータを動かして、舵角を制御する機構をつくります。

”フライトログの測定”は、以下の”フライトロガー”にあるような項目を計測できる市販のセンサを組み合わせて、電子工作します。
そして、一定間隔でデータを計測し、情報をSDカードに書き込む、通信で同期するという機構をつくるのです。

## フライトロガー

以下のようなデータを取得し，microSDカードに保存するための装置です．
- 対気速度
- 高度（琵琶湖の湖面までの距離）
- ...

## 操舵システム

サーボモーターを用いて機体後部の垂直尾翼を駆動しています．
パイロットの手元にあるレバーにより，繊細な操作が可能です．
