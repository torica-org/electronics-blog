\section*{Quaternion Euler's Formula}

Let $\mathbf{n}$ be a unit vector in 3D space, which can be viewed as a pure imaginary quaternion ($n_x^2 + n_y^2 + n_z^2 = 1$). 
Since $\mathbf{n}^2 = -1$, Euler's formula holds for quaternions:
\begin{equation}
    e^{\mathbf{n}\theta} = \cos\theta + \mathbf{n}\sin\theta
\end{equation}

For a 3D rotation by an angle $\theta$ around the axis $\mathbf{n}$, the rotation quaternion $q$ is expressed as:
\begin{equation}
    q = e^{\mathbf{n}\frac{\theta}{2}} = \cos\frac{\theta}{2} + \mathbf{n}\sin\frac{\theta}{2}
\end{equation}
